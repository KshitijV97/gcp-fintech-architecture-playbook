# 99 · Glossary

| Term | Meaning |
|---|---|
| **ADR** | Architecture Decision Record |
| **AML / AMLD / AMLR** | Anti-Money Laundering (EU Directive / Regulation) |
| **APP fraud** | Authorised Push Payment fraud: the victim is tricked into sending money |
| **ARB** | Architecture Review Board |
| **Assured Workloads** | GCP feature enforcing data location and personnel controls for a regulatory regime |
| **CAB / ECAB** | (Emergency) Change Advisory Board (ITIL) |
| **CAI** | Commission d'accès à l'information du Québec |
| **CDE** | Cardholder Data Environment (PCI DSS) |
| **CMEK** | Customer-Managed Encryption Keys (Cloud KMS) |
| **Crypto-shredding** | Making data unreadable by destroying its encryption key |
| **CUD** | Committed Use Discount |
| **DEK / KEK** | Data Encryption Key / Key Encryption Key (envelope encryption) |
| **DORA** | EU Digital Operational Resilience Act (applies from January 2025) |
| **DPA / CDPA** | Data Processing Agreement / Google Cloud Data Processing Addendum |
| **DPIA / PIA** | Data Protection Impact Assessment (GDPR) / Privacy Impact Assessment (Canada) |
| **DPO** | Data Protection Officer |
| **DSR / DSAR** | Data Subject (Access) Request |
| **EKM** | Cloud External Key Manager: keys held outside Google |
| **FINTRAC / PCMLTFA** | Canada's financial intelligence unit / Proceeds of Crime (Money Laundering) and Terrorist Financing Act |
| **GDPR** | EU General Data Protection Regulation |
| **IaC** | Infrastructure as Code |
| **Law 25** | Quebec's modernised private-sector privacy law |
| **OPC** | Office of the Privacy Commissioner of Canada |
| **OSFI B-10 / B-13 / E-21** | Canadian bank-regulator guidelines: third-party risk / technology and cyber risk / operational resilience |
| **PAM** | Privileged Access Manager (just-in-time IAM elevation) |
| **PIPEDA** | Personal Information Protection and Electronic Documents Act (Canada) |
| **PSC** | Private Service Connect |
| **PSD2 / PSR** | EU Payment Services Directive 2 / Payment Services Regulation |
| **RoPA** | Record of Processing Activities (GDPR Art. 30) |
| **RPAA** | Canada's Retail Payment Activities Act (Bank of Canada supervision of payment service providers) |
| **RROSH** | Real Risk Of Significant Harm (PIPEDA breach-notification threshold) |
| **SAR / STR** | Suspicious Activity / Transaction Report |
| **SCA** | Strong Customer Authentication (PSD2) |
| **SCC** | Security Command Center (or, in legal contexts, Standard Contractual Clauses) |
| **SDP** | Sensitive Data Protection (formerly Cloud DLP) |
| **TLPT** | Threat-Led Penetration Testing (DORA) |
| **VPC-SC** | VPC Service Controls |
| **WIF** | Workload / Workforce Identity Federation |
| **WORM** | Write Once, Read Many |
